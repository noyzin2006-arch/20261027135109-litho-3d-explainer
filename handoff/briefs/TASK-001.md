# 简报 TASK-001：光刻机原理 3D 交互讲解网页

## 任务

用户原话（一字不改）：**「做个3D模型将光刻机原理，输出网页」**（"将"为"讲解"之意）。

一句话场景：用户要一个**网页版 3D 交互作品**，把光刻机（光刻/photolithography）的工作原理讲清楚、讲漂亮——观众打开网页，能看懂"芯片是怎么被光刻出来的"，并且觉得这个东西本身就像一件精致的作品。

## 用户偏好证据

- 用户近两周连续让本机做了十几个同品类 3D 交互讲解网页：风力发电机、火山、三峡大坝、月球相位、中国地形、应县木塔、台风生成、3D 地形等。**这是他反复验证过、非常熟悉的一个品类**，他已经知道好的长什么样，审美阈值被拉得很高。
- 用户对这类作品的既有要求（从历史轮次提炼）：3D 必须真的可交互（拖拽旋转/缩放），不能只是被动播放的动画；讲解要**分步骤/分章节**带着观众走，不能一股脑全摆出来；中文界面；视觉上要克制、精致，拒绝廉价科幻感。
- 用户明确表达过的质量立意（原话要义）：**"最好的、最讲究的、设计上最考究的，对标当下最强模型的效果，方案选最优不选最省事"**——用户用本流程就默认要精品级。
- 用户嫌弃的东西：空泛的"高级感"堆砌、大段文字墙、糊成一团的 3D 场景、加载慢、手机上没法看。

## 验收

可判定条件，交付时逐条核对：

1. 网页可在现代浏览器（Chrome/Safari）直接打开运行，无需构建步骤或本地服务；加载后 3D 场景正常渲染，可拖拽旋转与缩放。
2. 内容覆盖光刻机原理的完整主线：晶圆与光刻胶 → 光源 → 掩模版 → 光学系统（透镜组）→ 曝光投影缩小成像 → 显影 → 刻蚀 → 套刻与步进重复（step-and-repeat），每一步观众都能通过场景变化直接"看见"。
3. 有分章节的分步讲解交互：观众按顺序推进（或点击章节），3D 场景与讲解文字联动；也能自由探索整体场景。
4. 全中文界面，文案准确、专业且通俗（EUV/DUV、数值孔径、缩短波长等关键概念有恰当的中文解释）。
5. 桌面与移动端都能正常观看与操作；首屏加载可感知进度，不白屏卡死。

## 背景与约束

- 本机环境：macOS arm64，Node 22 可用，Python 3.13 可用；无付费 API、无真机测试设备；测试全部在本机完成。
- 交付形态：纯前端静态网页（HTML/JS），实现技术由本机全权决定，**愿景案不要规定技术选型**。
- 既有约定（本机历史项目的惯例，供气质参考）：逻辑与数据分离、无第三方重型依赖时优先零依赖实现。
- 已试过可行：Three.js r160 级别的 WebGL 3D 在用户机器上表现良好；纯 Node 端软件光栅化也跑通过——说明本机驾驭 3D 渲染没有障碍，愿景可以放开描绘。
- 本轮明确不做：不做光刻机历史沿革长文科普、不做Quiz/测验环节、不做多语言、不做账号体系。
- 内容事实底线：光刻机原理属于公开科普知识，涉及具体厂商型号（ASML EUV 等）只做原理层面的示意，不编造具体参数数据；涉及的关键数字（如 EUV 波长 13.5nm、数值孔径量级）使用公开科普通识值即可。

## 参考素材（文字化描述）

本轮没有外部图片/PDF 素材，参考信息全部文字化如下：

1. **品类的既有优秀形态**（用户历史项目，本机已做过多个）：打开即见全屏 3D 场景 + 左侧或底部章节导航；每个章节相机自动飞到一个戏剧化的机位，同时场景中相关部件高亮/动画，其余部件半透明退后；文案短，讲清"这一步发生了什么"。这类结构已被用户认可，可作为体验骨架的参照基线。
2. **光刻机本体的视觉素材描述**（供想象参考，非照片）：现代光刻机是教室大小的精密箱体设备，外观是白色/银灰的机柜，内部才是核心：深紫外或极紫外光源腔、一排超净反射/折射光学系统、晶圆传输机械手、掩模版台与晶圆台。EUV 光刻机内部是**完全无空气的真空腔体**，因为 13.5nm 的光会被一切气体吸收；EUV 光学全部用**多层膜反射镜**（布喇格反射镜）而非透镜，因为该波长的光会被玻璃吸收。这些反直觉的事实是最好的"讲解爆点"。
3. **讲解主线的物理事实**：光刻的本质是"用光在晶圆的光刻胶上印刷电路图的缩影"——掩模版上的电路图版图经光学系统**缩小投影**（典型 4 倍缩小）到涂胶晶圆上，曝光→显影→刻蚀，一层一层往上叠，套刻精度达纳米级；光刻分辨率受瑞利判据支配（CD = k₁·λ/NA），"更短波长、更大数值孔径"是整个行业几十年技术演进的主旋律，从 436nm g-line 一路走到 13.5nm EUV。

## 本轮范围

做：一个面向大众到科技爱好者的高审美 3D 交互讲解网页，讲透光刻机原理主线，含分步章节、可交互 3D 场景、记忆点设计。

不做：光刻胶化学机理深挖、良率/经济学分析、厂商对比、历史年表长卷、测验环节、多语言。
